# Banking API

> **Status: work in progress**

Backend study project for a banking transactions API built with **Java 21, Spring Boot, PostgreSQL, JPA, Flyway, and Docker**.

The repository is currently focused on establishing the application foundation, persistence layer, database migrations, validation, observability, and local development environment.

## Current Stack

- Java 21
- Spring Boot
- Spring Web MVC
- Spring Data JPA
- PostgreSQL
- Flyway
- Bean Validation
- Spring Boot Actuator
- Lombok
- Maven
- Docker

## Current Stage

The project is in its initial implementation phase.

The current codebase provides the technical foundation for the API, including:

- Spring Boot project structure.
- PostgreSQL persistence configuration.
- JPA support.
- Flyway database migration support.
- Application validation dependencies.
- Actuator for health and operational endpoints.
- Docker-based local environment.

## Roadmap

Planned areas of development include:

- Account and transaction domain modeling.
- REST endpoints for banking operations.
- Transaction consistency and validation rules.
- Automated tests.
- Asynchronous processing or messaging where appropriate.
- Clear separation of application, domain, and infrastructure responsibilities.
- API documentation and local setup instructions.

The README will be expanded as these features are implemented.
